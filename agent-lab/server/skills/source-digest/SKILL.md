# Конспект источника

## Когда применять
Пользователь прислал одну или несколько ссылок и просит конспект/сводку/разбор. Не применять для вопросов без ссылки.

## Шаги
1. Загрузить страницу инструментом чтения веб-страниц. Если страница не открылась (ошибка, пейволл, капча) - сообщить об этом и остановиться, ничего не додумывая.
2. Извлечь: заголовок, авторов, дату публикации (если её нет - «дата не указана»), тип источника (первичный: статья, спецификация, документация, репозиторий; вторичный: блог, пересказ).
3. Выписать 3-5 ключевых утверждений. К каждому - дословная цитата до 25 слов из источника. Утверждения без цитаты не включать.
4. Отметить, что из источника относится к теме из MEMORY.md (оптимизация 3D в браузере), одной строкой.
5. Сохранить конспект в `/opt/data/research/digests/ГГГГ-ММ-ДД-<короткий-slug>.md` (создать каталог при необходимости).
6. Ответить пользователю: путь к файлу, вывод в 1-2 предложениях и строку «Источников: N, из них первичных: M».

## Проверка
Файл существует, в нём есть раздел «Цитаты», число цитат равно числу утверждений.
