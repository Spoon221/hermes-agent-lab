meshkit - changelog

Fictional library. Test page for experiment P4 at agent.simakov.space.

3.1.0

  • Added mergeByMaterial() helper.
  • Fixed memory leak in InstancedPool.dispose().
  • Breaking: LodGroup distances are now in world units instead of screen percentage.

3.0.0

  • Breaking: dropped support for WebGL 1; WebGL 2 or WebGPU is required.
  • Breaking: mergeGeometries(list, useGroups) now takes an options object: mergeGeometries(list, { groups }).
  • New: experimental WebGPU renderer backend.
  • Breaking: the default export was removed; use named imports only.
  • Deprecated: autoCull option (will be removed in 4.0).
  • Performance: frustum culling is 2.3× faster on scenes with more than 10k objects.

2.4.2

  • Fixed TypeScript types for InstancedPool.
  • Breaking (reverted in 2.4.3): renamed pool.size to pool.capacity.
